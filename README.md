# zzyzhbs.github.io

Personal homepage of Shengqi Yuan, served by GitHub Pages at https://zzyzhbs.github.io.

Built on [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) (MIT), itself derived from
[academicpages](https://github.com/academicpages/academicpages.github.io) and
[Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes). The analytics snippet, the Google Scholar
crawler and the MathJax CDN script of the template were removed; the page loads no third-party resources.

Page text and the figures under `images/projects/` are by Shengqi Yuan. Template code stays under the MIT
license in `LICENSE`.

## Edit

- Content: `_pages/about.md`
- Left column (name, links, CV): `_config.yml`
- Styles specific to this site: the end of `assets/css/main.scss`

## Preview locally

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.
